# ActivityChart

Gráfico de colunas de commits por mês em SVG puro (sem biblioteca de gráficos), com `<title>` nativo como tooltip.

**Fornece:** `title`, `months: [{ label, year?, commits, full? }]` (12 meses).

- Mantenha a tabela alternativa em `<details>` ("Ver dados em tabela") ao lado, como no site.
- Colunas em `chart` (sky-600) nos dois temas; grade em `border`; eixos em `ink-subtle`.
