# Timeline

Linha do tempo da seção Evolução: ponto colorido, período em mono, StatusBadge, título, tópicos como TechTag e link de certificado.

**Fornece:** `items: [{ period, status, title, topics?, link? }]` vindos de `roadmap.json` (já ordenados: concluídos, em andamento, planejados).

- O ponto usa `success-dot` / `warn-dot` / `neutral-dot`; a palavra do badge sempre acompanha.
- "Ver certificado" só quando houver `link`.
