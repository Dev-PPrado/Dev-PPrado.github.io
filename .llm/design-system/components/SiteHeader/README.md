# SiteHeader

Header fixo translúcido com a marca (as três barras do favicon), navegação por âncoras e ThemeToggle.

**Fornece:** `name`, `links: [{ href, label }]`, `current` (href ativo → `aria-current`), `homeHref`, `themeToggle={false}`.

- A navegação some abaixo de 640px, como no site; mantenha o skip link "Pular para o conteúdo" antes do header.
