# TechLogo

Logo de tecnologia em SVG inline (Simple Icons, CC0), na cor da marca ou monocromático.

**Fornece:** `tech` (slug como `python`, `apacheairflow`, ou nome como "Apache Airflow", "PostgreSQL"), `size` (px, padrão 24), `variant` (`brand` | `mono`), `decorative` quando há texto ao lado.

- `brand` troca automaticamente para `ink-strong` quando a cor da marca some no tema (pandas, NumPy, GitHub, Anthropic, Ollama no escuro; Jupyter, Parquet, DuckDB, LangChain, Hugging Face no claro).
- Techs sem marca no Simple Icons (AWS, SQL Server, dbt, PLC Rockwell, OPC UA, SCADA, MES, SQLite) aparecem como monograma tipográfico — nunca desenhe ou aproxime o logo oficial.
- Use `mono` dentro de botões e na barra do CodeBlock; `brand` em StackCard, TechTag e listas.
- Siga as diretrizes de marca de cada projeto: não distorça, não recolora fora destes dois modos.
